# LG Interactive Onboarding

## Initialize the project

### Prerequisites
- Flutter SDK installed and on your PATH
- Android Studio or Xcode (for mobile builds)

### Steps
1. Verify Flutter is available:
	```bash
	flutter --version
	```
2. Install dependencies:
	```bash
	flutter pub get
	```
3. List available devices:
	```bash
	flutter devices
	```
4. Run the app:
	```bash
	flutter run
	```

### Optional: Create platform builds
- Android APK (debug):
  ```bash
  flutter build apk --debug
  ```
- Web:
  ```bash
  flutter build web
  ```
